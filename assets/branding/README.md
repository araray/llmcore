# llmcore — brand assets

Part of the wairu ecosystem family (llmcore · wairu · semantiscan · grimoire · confy):
one construction grid, a shared slate tile, one accent per project.

| file | use |
|---|---|
| `mark_llmcore.svg` | the mark, transparent, 256 viewBox — source of truth for anything vector |
| `mark_1024_llmcore.png` | mark on transparent, 1024² |
| `tile_llmcore.svg` / `tile_1024_llmcore.png` | mark on the app tile (icons) |
| `tile_llmcore_small.svg` | bolder variant used to rasterise sizes ≤ 48 px |
| `icon_llmcore_{512,256,128,64,48,32,16}.png` | icon ladder |
| `favicon_llmcore.ico` | 16/32/48 favicon |
| `logo_dark_llmcore.png` / `logo_light_llmcore.png` | README lockup (tile + wordmark + tagline), 1600×400 |
| `social_llmcore.png` | 1280×640 GitHub social preview (set under repo *Settings → Social preview*) |

Wordmark: Lato Black. Base slate `#0F172A` / `#F8FAFC`. Editable Krita sources
(`.kra`) live with the design workspace, not in this repo.
